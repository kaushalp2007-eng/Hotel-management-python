# Hotel Management System 🏨🐍
A beginner-friendly, console-based Hotel Management System written in Python. 
This project is created for learning programming fundamentals, working with data structures,
handling user input, and building interactive command-line applications.

### 🌟 What You Will Learn From This Project
*Control Flow: Using while loops, if-elif-else conditions to build a continuous menu system.
*Data Structures: Managing data using Python lists and dictionaries (storing guest details, room numbers, and billing information).
*Functions & Modularity: Breaking down a program into smaller, reusable blocks of code for different tasks (booking, checking out, displaying records).
*User Input Handling: Taking inputs, validating choices, and preventing program crashes from invalid typing.

### 🎮 How the Program Works (Features)
When you run the script, it shows a text-based menu in your terminal where you can:

*Book a Room: Enter guest details (Name, Address, Phone) and assign a room type/number.

*Calculate Bill: Compute the total charge based on the duration of stay and room rent.

*Display Customer Records: View a list of currently checked-in guests.

*Exit: Safely close the application loop.
